Review before installing

      
Installs every message supplied by this pack, including work in progress. Missing messages use native fallback. This is local installation, not redistribution.
Export includes Done translations (optionally WIP), credits and fonts. Unchanged source templates, private notes and Not started messages are excluded.

      

      
ROM-derived source projects are local-only. Font-file validation does not prove every Unicode glyph is covered. In-game font readiness checks still apply. Credits are editable attribution, not cryptographic provenance.

  2. Open the system overlay → Localization → Text source and choose the package name above.
  3. Set Text rendering to Enhanced. Native intentionally keeps the original US text and font.
