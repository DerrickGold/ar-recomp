Font stack

The primary font sets the look. Ordered fallbacks supply characters it cannot draw. The game keeps its high-resolution rendering, mosaic settings and per-character color bands.

    Choose TTF/OTF files, up to 64 MiB each, with at most eight fallbacks. Dependencies are copied into this project when saved. Removing a font here does not delete the original file or its credit notices.

    Include the font's redistribution license under Details & credits before publishing. A license notice is not a grant of permission.

    Layout constraints

      Source reference

      
          
      Write ordinary text. Use @line for an intentional line break and @page for another page. Delete a page break to merge pages. Keep native @anchor controls in order; validation prevents unsafe changes. Use {{ and }} for literal braces, @@ for a leading @, and \# or \; for a leading comment marker.
      
          
      
          
      Script preview
      Logical pages and controls, not the game's final wrapping, font, mosaic effect or scrolling. Validate appearance in game.
