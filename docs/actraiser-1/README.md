# ActRaiser 1

Gameplay, regional releases, content authoring, and native data for the first
ActRaiser. Memory addresses, routine names, simulation behavior, and SRAM
layouts in this directory belong to AR1. The USA release is the default unless
a reference explicitly names another release. Regional addresses are not
interchangeable even within AR1.

For application controls, building, and shared authoring tools, see the
[documentation index](../README.md) and [player manual](../manual.md).

- [Regional settings](regional-settings.md) — campaign presets, independent
  options, activation timing, and saving.
- [Regional media](regional-media.md) — extracting and using artwork and music
  from the supported AR1 regional ROMs.
- [Regional differences](regional-differences.md) — a comparison of the retail
  releases, with unresolved findings identified.
- [Randomizer](randomizer.md) — seeded campaign settings and save compatibility.
- [Action environments](action-environments.md) — Aitos, Marahna, and Death Heim

- [Unused content and oddities](unused-content.md) — debug facilities, remnants,
  and unexplained assets, with evidence limits.
- [Modern SIM menu](../manual.md#modern-sim-menu) — the optional town interface.
