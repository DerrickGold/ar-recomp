Choose game folder

Choose where your playable game will live. The default is a portable ActRaiserRecomp folder beside the Builder. Nothing is written to the game folder until you continue.

Choose or create a dedicated folder, not the application file itself. We will use this exact path without adding another subfolder.

Review destination

    Only generated game applications and their dependencies are replaced. Saves, settings, installed language packs and custom assets are preserved. The folder is never cleared. Close the game and any other Builder using this installation before continuing.
