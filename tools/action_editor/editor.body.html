Complete effect field

This definition replaces its bundled field. Source contacts, shapes, profiles, colors and motion are explicit. Editing values retains the shared geometry kernels and bounded batches.

Appearance

100% preserves brightness; 0% is black; 200% doubles it. Matching brightness boxes merge without stacking, using the strongest fade coverage. Different brightness values multiply. Fades are measured inward from each edge in map pixels. Zero disables that edge’s fade; opposing fades shrink together if the box is too small. Diorama interpolates brightness across its scenery mesh.

Cloud-break lighting

This distant atmosphere affects the background and its cloud banks, not actors. Shared diorama renderer only.

Clear sky artwork

Palette/color indices identify the clear sky in the original BG2 artwork. Stars fade under other colors, including moving clouds. Use none to disable this mask.

Height sets the maximum strike reach. Grounded bolts and branches stop on the first matching terrain pixel in the scrolling BG2 artwork; transparent pixels are skipped. If no ground is within reach, that strike is omitted. The shared preview shows the actual contact. These controls use BG2 fixed-point anchoring.

Trace the visible surface, up to 16 points within 512px. Cloud ground paths run left to right; leave their points empty for airborne clouds. Paths are authored guides: redraw them after changing the terrain.

Particle movement and size

Sizes are radii in game pixels. Travel uses pixels per cycle: negative Y rises, positive Y falls, zero Y stays within the area. Spread 0 forms a column; 1 fills the width. Seed fixes the pattern when scrubbing. Changing area size keeps particle size fixed.

Ground mist searches down through the area to the first supported floor in each column. Mist height controls its depth above that floor. Free mist is airborne.
